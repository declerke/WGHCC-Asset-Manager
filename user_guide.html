1. Getting Started — Login & First-Time Setup

Launching the Application

Double-click wghcc_asset_manager.pyw to open the system. A login window will appear.

💡 Rename the file from .py to .pyw to prevent the black command-prompt window from appearing in the background.

Logging In

  1. Enter your Username in the first field.
  2. Enter your Password. Click Show to reveal what you are typing.
  3. Press Enter or click Sign In.

Default Credentials (First Launch)

UsernamePasswordRole
adminadmin123Administrator
⚠️ On first login you will be asked to set a new password immediately before you can proceed. Choose a strong password and keep it safe.

Changing Your Password

At any time, click Change Password at the bottom of the left sidebar. Enter your new password twice and click Save Password.

2. Navigating the Application

The main window is divided into two areas:

  • Sidebar (left) — shows your username, role, and navigation buttons.
  • Content area (right) — displays the active view.
Sidebar ButtonWhat It OpensWho Can Access
📊 DashboardLive KPIs, charts, and alertsAll users
📦 InventoryFull asset list — add, edit, removeAll users
📋 Audit TrailComplete history of every changeAll users
🔧 MaintenanceService and repair recordsAll users
⚙️ Admin PanelUser account managementAdmin only

Dark / Light Mode

Use the Dark Mode toggle at the bottom of the sidebar to switch themes at any time.

Logging Out

Click the red 🚪 Logout button at the bottom of the sidebar. You will be returned to the login screen. Closing the window entirely will exit the application.

3. Dashboard

The Dashboard gives an at-a-glance overview of the entire inventory. It refreshes every time you navigate to it.

KPI Cards

CardWhat It Shows
Total AssetsTotal number of distinct asset records in the system
AvailableAssets whose status is Available
BorrowedAssets currently checked out or assigned
Total ValueSum of Purchase Price × Quantity across all assets (KES)

Charts

  • Assets by Category — pie chart showing the proportion of each equipment type.
  • Asset Status Breakdown — bar chart showing how many assets are in each status.

Alerts Strip

The alerts strip at the bottom of the dashboard automatically highlights two conditions:

  • WARRANTY — an asset whose warranty expires within 90 days, or has already expired.
  • LOW STOCK — an asset whose quantity is at or below its Minimum Stock threshold.

A green ✓ No active alerts message confirms all assets are within normal parameters.

4. Managing Inventory

Viewing Assets

The Inventory view shows all assets in a table. Click any column heading to sort by that column. Double-click a row to open the edit form.

Searching and Filtering

  • Search box — type any part of the asset name, serial number, location, brand, or model. Results update as you type.
  • Category filter — narrow the list to one equipment category.
  • Status filter — show only assets in a particular status (Available, Borrowed, etc.).

The status bar at the top-right shows how many items match the current filters.

Row Colour Coding

ColourMeaning
Red tintWarranty expires within 30 days or has expired
Yellow tintQuantity is at or below the minimum stock level

Adding a New Asset

  1. Click + Add Asset in the toolbar.
  2. Fill in the form. Fields marked with * (Name and Category) are required.
  3. Click Save. The asset appears in the list immediately and the action is recorded in the Audit Trail.

Editing an Asset

  1. Click the asset row to select it, then click ✎ Edit — or simply double-click the row.
  2. Update any fields and click Save.
  3. Every changed field is individually recorded in the Audit Trail with the old and new values.

Removing an Asset

  1. Select the asset row.
  2. Click ✕ Remove.
  3. Confirm the deletion in the prompt. This action cannot be undone.
🚫 Deleting an asset permanently removes it from the database. Consider setting the status to Retired instead of deleting if you want to keep a historical record.

Logging a Maintenance Record for an Asset

  1. Select the asset row.
  2. Click 🔧 Maintenance.
  3. Fill in the service details and click Save Record.

The record will appear in the Maintenance Log view and in the Audit Trail.

5. Importing & Exporting Data

Downloading the Import Template

  1. In the Inventory toolbar, click ↻ Template.
  2. Choose where to save the file and click Save.
  3. Open the file in Microsoft Excel. Each column header corresponds to an asset field.

Importing Assets from Excel

  1. Fill in the template. Name and Category are the only required columns.
  2. Save the file in .xlsx format.
  3. In the Inventory toolbar, click ⬇ Import Excel and select your file.
  4. A summary will show how many rows were imported and any errors encountered.
⚠️ Rows with a Serial Number that already exists in the database will be skipped to avoid duplicates. Check the error summary after importing.

Exporting the Current View

  1. Apply any filters you want (the export respects the current search/filter).
  2. Click ⬆ Export View.
  3. Choose a file name and location. The file will open directly in Excel.

Exporting the Audit Log or Maintenance Log

Each of those views has an ⬆ Export button in the toolbar that works the same way.

6. Maintenance Log

The Maintenance Log is a chronological record of every service, repair, or upgrade carried out on any asset.

Records are added through the Inventory view (select an asset → 🔧 Maintenance). Each record captures:

FieldDescription
Service DateDate the work was performed (YYYY-MM-DD)
Service TypeRepair, Replacement, Upgrade, Inspection, Cleaning, Software Update, or Other
DescriptionFree-text notes about what was done
Cost (KES)Cost of the service, if applicable
Performed ByName of the technician or vendor
Next Service DateRecommended date for the next service

Click ⬆ Export to download the full log as an Excel file.

7. Audit Trail

The Audit Trail is a tamper-evident record of every action performed in the system — who did it, what they changed, and when.

Action Types

ActionMeaning
ADDA new asset was created
EDITA field on an existing asset was changed. The old and new values are both recorded.
DELETEAn asset was permanently removed
MAINTENANCEA maintenance record was logged
LOGIN / LOGOUTA user signed in or out

Searching the Audit Trail

Use the filter box to search by username, action type, or asset name. Results update as you type.

Exporting

Click ⬆ Export to save the full audit log as an Excel file — useful for compliance reviews or IT audits.

ℹ️ Audit records cannot be edited or deleted from within the application, ensuring an accurate and trustworthy history.

8. Admin Panel — User Management

The Admin Panel is visible only to users with the Admin role.

Creating a New User

  1. Click + Create User.
  2. Enter a username, a temporary password (minimum 6 characters), and select a role (Staff or Admin).
  3. Click Create User. The new user will be prompted to change their password on first login.

Deactivating a User

  1. Select the user from the list.
  2. Click ✕ Deactivate. The user will no longer be able to log in.
  3. To re-enable access, select the user and click ✓ Activate.
🚫 The admin account cannot be deactivated. Always ensure at least one active Admin account exists.

Resetting a User's Password

  1. Select the user from the list.
  2. Click 🔑 Reset Password.
  3. A temporary password will be generated and shown on screen. Share it with the user — they will be required to change it on next login.

Roles Explained

RoleCapabilities
AdminFull access including User Management and all inventory operations
StaffCan view, add, edit, and log maintenance for assets; cannot manage users

9. Recovering a Forgotten Password

If you cannot log in because you have forgotten your password, use the built-in recovery flow.

  1. On the Login screen, click Forgot password? below the password field.
  2. Enter the Recovery Code. This code is held by the IT Administrator.
  3. Select the username whose password you need to reset from the dropdown.
  4. Enter and confirm the new password.
  5. Click Reset Password. You can now log in with the new password.
⚠️ Keep the Recovery Code confidential. It provides full password-reset access to all accounts. Store it securely — not on the same machine as the application.
ℹ️ If the recovery code is also lost, contact the system developer to perform a database-level reset.
